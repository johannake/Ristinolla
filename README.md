# Ristinolla

Ristinolla peli, jossa tietokoneen siirto määritellään minimax-algoritmilla.
Perus minimax-ristinollaa on muokattu siten että pelaaja saa valita joko helpon tai vaikean version. Helpossa versiossa tietokone "tekee virheitä" 50% todennäköisyydellä, eli pelaa toisin kuin minimax algoritmin mukaan mentäessä. Vaikeassa versiossa virheiden todennäköisyys on 10%.

Pelin alussa arvotaan kummalla on ensimmäinen siirtovuoro, pelaajalla vai tietokoneella. Kierroksen jälkeen pelaajalla on mahdollisuus pelata uusi kierros tai lopettaa peli.
